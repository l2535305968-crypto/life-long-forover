# 让 AI 说话不干瘪：配音台接入方案

> 背景：用户反馈 AI 的对话语言"干瘪"。已做两层：**文字层**（改提示词，已验证有烟火气）+ **声音层**（用德海科技配音工作台替换浏览器机器音，方案如下）。

## 已完成：文字层加温（已验证）

`web/js/ai/prompt.js` 的访谈提示词新增"说话的味道"规则：

- 像坐炕头唠嗑，别像客服/老师提问、别端着
- 多用"咱/您/那会儿/咋/啥/呗"口语词
- 该带语气就带："哎/嘿/那可不/可不是嘛"
- 别干巴巴甩问题，先接老人的话再问

实测（真实 DeepSeek）：
- 改前：那细粮可稀罕了吧？是不是就逢年过节才舍得吃一回？
- 改后：那细粮可是稀罕物，估摸着得等过年过节才舍得端上桌吧？

### 又加了一层：先接情绪，再问事（本轮）

反馈"还是太 AI、情绪不够"后，提示词新增"情绪铁律"：

- **先接情绪再问事**：老人话里的苦、甜、骄傲、心酸要先接住（"那会儿可真不容易""哎哟，听着都心疼"），再顺势带问题；绝不装没听见直接甩问句。
- **别每句都非得是问句**：老人说得动情时，一句回应就够，问题留到下一句。
- **共情要像人，别像书**：禁"我理解您的心情""您辛苦了"这类书面共情；要叹就叹、要心疼就心疼，情绪跟着老人走。
- 提示词里给了一对"差/好"例句做锚（干巴巴问句 vs 先共情再问）。

实测（真实 DeepSeek，node test/prompt-warmth-check.mjs，4 个带情绪场景 4/4 过）：
- 老人说"上学要走三里地土路，冬天冻得脚生疮"→ AI："哎哟，那雪地里一脚一脚的，听着都心疼。那时候上学，您最怕的是啥呀？"
- 老人说"过年最盼白面饺子，蹲灶台边等"→ AI："哎哟，那灶台边的香味儿，隔着几十年都能闻着。过年除了饺子，咱家还兴啥热闹事儿不？"

## 配音台是什么（诚实定位）

`D:\AI\dyjx\video-voiceover-cloner\video-voiceover-cloner`（德海科技配音工作台）：
- 模型：**Qwen3-TTS**（0.6B Base 合成 + 1.7B VoiceDesign 设计音色）+ **IndexTTS2**（声音克隆、情感）
- 定位：**短视频配音**——"分析参考视频→设计新音色→批量念稿"，剪映/CapCut 输出
- 依赖：GPU（约 8GB 显存推荐，CPU 也能跑但慢），模型已在本机 `.runtime/models`
- 工作台跑在 `http://127.0.0.1:7860`（gradio）

## 声音层接入：两条路

### 路 A（推荐，要真跑起来）：独立 Qwen3-TTS 适配器

写一个 `tools/qwen3_tts_server.py`：用配音台的 Qwen3-TTS Base 模型，起一个简单 HTTP `/tts`（文字→wav），让《人生之书》的 `/api/tts` 代理它，浏览器播放这个暖音色，替代 speechSynthesis。

- 需要：配音台运行环境（`.runtime\python` + 模型）+ GPU；一次冷启动加载模型后，每句合成约 1-3 秒
- 待做：读 `scripts/voiceover_engine.py` 里 Qwen3-TTS 的调用方式，写适配器，接 `/api/tts`，浏览器 tts.js 改为播放音频（保留 speechSynthesis 兜底）

### 路 B（零代码，但每次要开工作台）：调 gradio 接口

先启动 `启动德海科技配音工作台.ps1`，在界面里设计好一个"自然亲和"的暖音色，之后用 gradio 的 API 把 AI 的话送进去念。

- 需要：工作台每次开着；流程是"设计音色→批量念稿"，不是实时对话接口，每句要走完整个管线，延迟更高
- 适合：预生成常用问候/开场，不适合逐句实时聊天

### 怎么把它跑起来（在你自己终端里，沙箱装不了外部环境）

1. 装依赖（一次）：powershell -ExecutionPolicy Bypass -File tools\install-qwen3tts.ps1
2. 起温暖声音服务：powershell -ExecutionPolicy Bypass -File tools\start-voice-servers.ps1
   或单独：& 'D:\AI\ai_voice\Qwen3TTS-Env\venv\Scripts\python.exe' tools\qwen3_tts_server.py --port 7861
3. 确认 .env 有 TTS_URL=http://127.0.0.1:7861/tts（默认就是这个），重启 node server/server.mjs
4. 验证：浏览器开 http://localhost:8788/api/health → hasTts: true
   直接试一句：curl -X POST http://localhost:8788/api/tts -H "content-type: application/json" -d '{"text":"姥爷，您慢慢说。"}' -o out.wav

首次 /tts 会先用 VoiceDesign 设计一个「自然亲和」的合成音色（存 tools/voice/anchor.wav，约 1~3 分钟），
之后每句用 Base 模型克隆这个音色念，约 1~5 秒/句。有 NVIDIA 显卡自动走 CUDA，没有就用 CPU（慢一些但能用）。
