# 访谈方法论 → 引擎实现映射

本文把"倪萍式访谈"的每一条铁律，落实到 `web/js/core/engine.js` 的具体判定点。写本文的目的：让人知道"不会查户口"不是一句口号，而是代码里能指认、能测试的规则。

## 铁律与实现点

### 1. 问题具体到生活细节
- **数据侧**：`bank.js` 173 条问题全部是"您小时候睡炕还是床""茧子长在哪个指头上"这类具体问法，禁止"请描述您的一生"。
- **实现侧**：`engine.pickFreshQuestion` 只从话术库挑，带话题新颖度加权，保证覆盖面而不是逮着一个问。

### 2. 顺着上一句延伸，不照清单念
- **实现侧**：`engine.pickExtension`。
- 优先级：上一问**带条件的追问**（命中关键词才问）＞无条件追问（兜底）＞全局触发式规则（`followUpRules` 关键词）。
- 测试锁死：说"苞米"必须追"那细粮留着啥时候吃"，而不是随机抽一句。

### 3. 允许拒绝
- **实现侧**：`engine.respond` 的 `INTENT.REFUSE` 分支。
- 不追问、不劝；把当前话题进 `refusedTopics` 黑名单，并清掉上一问的追问上下文，防止换个说法又绕回来。
- 敏感上限也会被"刚拒绝过"暂时压低（`sensitivityCeiling`）。

### 4. 允许沉默、允许重复
- **沉默**：`INTENT.SILENCE` 分支。陪着等不催；连续两轮沉默才换一个更小的、零敏感的具体问题。
- **重复**：`isRepeatAgainstHistory` 用字符 bigram 相似度识别，命中后回 `repeatReplies`（"您再说说，我爱听"），**绝不**点破"您刚说过了"。重复被记进 `session.repeats`，当作"这件事对他要紧"。

### 5. 不查户口
- **数据侧**：全库无一条索取姓名/年龄/职业/住址/身份证的问题。
- **模型侧**：`prompt.js` 的系统提示词第 1 条就禁。
- **实现侧**：测试里跑 50 轮冷启动，断言任何问题都不含"叫什么名字/多大岁数/住址/身份证"。

### 6. 敏感话题看暖场程度
- **实现侧**：`sensitivityCeiling`。暖场轮数不够，敏感问题根本不在候选池里；且被拒后上限回落。

## AI 与引擎的分工

- **引擎**管分寸：该不该问、问什么方向、拒绝/沉默/重复怎么接。
- **DeepSeek**管说得自然：把引擎挑中的问题，润色成"像孙辈在说"的一句（`adapter.polishQuestion`）。
- 断网/没 Key 时，访谈不中断，退回引擎的确定性问句（`nextAiLine` 的兜底）。

## 一句话总结

方法论被拆成三层——数据（bank）、规则（engine）、语气（prompt）——每一层都能被 `node test/run-all.mjs` 验证，而不是只存在文档里。
