# 部署指南

两条路，按阶段用：

- **开发 / 自己家里用**：本机 `node server/server.mjs`，手机真机用 cloudflared 隧道（见 A）。
- **长期 / 给多个家人用**：部署到 Cloudflare Pages（见 B），自带 https，手机能加桌面、能用麦克风。

---

## A. 手机真机测试（cloudflared 临时隧道）

手机要"加到桌面 + 用麦克风"必须 https。cloudflared 把本机服务变成一个 https 网址。

1. 下载 cloudflared：<https://github.com/cloudflare/cloudflared/releases/latest>
   - Windows 64 位选 `cloudflared-windows-amd64.exe`，改名 `cloudflared.exe` 放到固定目录（比如 `C:\tools\`）。
2. 先起本机服务：`node server/server.mjs`
3. 再开隧道：
   ```
   cloudflared tunnel --url http://localhost:8788
   ```
   它会吐一个 `https://xxxx.trycloudflare.com` 网址，微信里发给家人，手机点开就能用（这个网址每次会变，适合临时测试）。

---

## B. Cloudflare Pages 部署（正式）

本项目的后端已写成了 Pages Functions（`functions/` 目录），前端是纯静态（`web/` 目录）。

### 方式一：命令行（推荐，可把 Key 用 secret 存好）

```bash
# 1. 装 wrangler（Cloudflare 官方 CLI）
npm install -g wrangler
# 2. 登录（浏览器 OAuth）
wrangler login
# 3. 部署（web/ 是静态根，functions/ 自动当后端）
wrangler pages deploy web --project-name renshengzhishu
# 4. 把 Key 存成 secret（不会出现在代码里，也看不到明文）
wrangler pages secret put DEEPSEEK_API_KEY --project-name renshengzhishu
#    按提示粘贴 sk-... ，回车
```

部署完会得到一个 `https://renshengzhishu.pages.dev` 之类的地址，手机上打开 → 分享 → 添加到主屏幕。

### 方式二：网页控制台（不想装 CLI）

1. 打开 <https://dash.cloudflare.com/> → Workers & Pages → Create → Pages → **Direct Upload**。
2. 项目名随便填，把本地 `web/` 文件夹整个拖进去上传。**注意**：Direct Upload 不带 `functions/`，所以纯网页上传只能得到"前端 + 浏览器内置语音"版本；要完整后端（DeepSeek 代理），用方式一的 CLI，或连 Git 仓库。
3. 环境变量：项目 Settings → Environment variables → 加 `DEEPSEEK_API_KEY`（值填你的 Key）。
4. 连 Git 时：Build command 留空，Build output directory 填 `web`。

### 环境变量清单

| 变量 | 必填 | 说明 |
|------|------|------|
| `DEEPSEEK_API_KEY` | 是 | DeepSeek Key |
| `DEEPSEEK_MODEL` | 否 | 默认 `deepseek-chat` |
| `DEEPSEEK_BASE_URL` | 否 | 默认 `https://api.deepseek.com` |

### 说明

- Pages 是 https，麦克风、加到桌面、Service Worker 都满足条件。
- 限流：本机版有内存限流；Pages 版靠 Cloudflare 自带的防护（免费额度对家庭够用）。若担心被刷，可在 Cloudflare 加 WAF 规则。
- **重要限制：Pages 上只有 DeepSeek 对话，没有讯飞方言识别。** 讯飞"语音听写"只有 WebSocket 接口，Cloudflare Workers/Pages 不能主动连外部 WebSocket，所以 `functions/api/asr.js` 只是诚实占位（返回 503 说明）。Pages 部署时语音会自动降级为浏览器内置识别（仅 iPhone 可用）或打字。

## C. 要完整语音（含讯飞方言）→ 用 Cloudflare Tunnel

`server.mjs` 已经同时代理 DeepSeek 和讯飞 ASR。要公网访问且语音完整，用命名隧道（免费、稳定、固定域名）：

```bash
# 1. 起本地服务
node server/server.mjs
# 2. 登录
cloudflared tunnel login
# 3. 建命名隧道（一次）
cloudflared tunnel create renshengzhishu
# 4. 绑定域名（一次，域名需托管在 Cloudflare）
cloudflared tunnel route dns renshengzhishu shu.yourdomain.com
# 5. 运行
cloudflared tunnel run renshengzhishu
```

这样 `https://shu.yourdomain.com` 是稳定公网地址，DeepSeek 和讯飞 ASR 都照常，无需 VPS、无需付费、无需改任何代码。
