# 部署指南

两条路，按阶段用：

- **开发 / 自己家里用**：本机 `node server/server.mjs`，手机真机用 cloudflared 隧道（见 A）。
- **长期 / 给多个家人用**：部署到 Cloudflare Pages（见 B），自带 https，手机能加桌面、能用麦克风。

---

## A. 手机真机测试（cloudflared 临时隧道）

手机要"加到桌面 + 用麦克风"必须 https。cloudflared 把本机服务变成一个 https 网址。

1. 下载 cloudflared：<https://github.com/cloudflare/cloudflared/releases/latest>
   - Windows 64 位选 `cloudflared-windows-amd64.exe`，改名 `cloudflared.exe` 放到固定目录（比如 `C:\tools\`）。
2. 先起本机服务：`node server/server.mjs`
3. 再开隧道：
   ```
   cloudflared tunnel --url http://localhost:8788
   ```
   它会吐一个 `https://xxxx.trycloudflare.com` 网址，微信里发给家人，手机点开就能用（这个网址每次会变，适合临时测试）。

---

## B. Cloudflare Pages 部署（正式）

本项目的后端已写成了 Pages Functions（`functions/` 目录），前端是纯静态（`web/` 目录）。

### 方式一：命令行（推荐，可把 Key 用 secret 存好）

```bash
# 1. 装 wrangler（Cloudflare 官方 CLI）
npm install -g wrangler
# 2. 登录（浏览器 OAuth）
wrangler login
# 3. 部署（web/ 是静态根，functions/ 自动当后端）
wrangler pages deploy web --project-name renshengzhishu
# 4. 把 Key 存成 secret（不会出现在代码里，也看不到明文）
wrangler pages secret put DEEPSEEK_API_KEY --project-name renshengzhishu
#    按提示粘贴 sk-... ，回车
```

部署完会得到一个 `https://renshengzhishu.pages.dev` 之类的地址，手机上打开 → 分享 → 添加到主屏幕。

### 方式二：网页控制台（不想装 CLI）

1. 打开 <https://dash.cloudflare.com/> → Workers & Pages → Create → Pages → **Direct Upload**。
2. 项目名随便填，把本地 `web/` 文件夹整个拖进去上传。**注意**：Direct Upload 不带 `functions/`，所以纯网页上传只能得到"前端 + 浏览器内置语音"版本；要完整后端（DeepSeek 代理），用方式一的 CLI，或连 Git 仓库。
3. 环境变量：项目 Settings → Environment variables → 加 `DEEPSEEK_API_KEY`（值填你的 Key）。
4. 连 Git 时：Build command 留空，Build output directory 填 `web`。

### 环境变量清单

| 变量 | 必填 | 说明 |
|------|------|------|
| `DEEPSEEK_API_KEY` | 是 | DeepSeek Key |
| `DEEPSEEK_MODEL` | 否 | 默认 `deepseek-chat` |
| `DEEPSEEK_BASE_URL` | 否 | 默认 `https://api.deepseek.com` |

### 说明

- Pages 是 https，麦克风、加到桌面、Service Worker 都满足条件。
- 限流：本机版有内存限流；Pages 版靠 Cloudflare 自带的防护（免费额度对家庭够用）。若担心被刷，可在 Cloudflare 加 WAF 规则。
- **重要限制：Pages 上只有 DeepSeek 对话，没有讯飞方言识别。** 讯飞"语音听写"只有 WebSocket 接口，Cloudflare Workers/Pages 不能主动连外部 WebSocket，所以 `functions/api/asr.js` 只是诚实占位（返回 503 说明）。Pages 部署时语音会自动降级为浏览器内置识别（仅 iPhone 可用）或打字。

## C. 要完整语音（含讯飞方言）→ 用 Cloudflare Tunnel

`server.mjs` 已经同时代理 DeepSeek 和讯飞 ASR。要公网访问且语音完整，用命名隧道（免费、稳定、固定域名）：

```bash
# 1. 起本地服务
node server/server.mjs
# 2. 登录
cloudflared tunnel login
# 3. 建命名隧道（一次）
cloudflared tunnel create renshengzhishu
# 4. 绑定域名（一次，域名需托管在 Cloudflare）
cloudflared tunnel route dns renshengzhishu shu.yourdomain.com
# 5. 运行
cloudflared tunnel run renshengzhishu
```

这样 `https://shu.yourdomain.com` 是稳定公网地址，DeepSeek 和讯飞 ASR 都照常，无需 VPS、无需付费、无需改任何代码。

## D. 云服务器托管（真正"永久放在别人手机上"，推荐正式交付用）

> 前面 A/B/C 都有个共同前提：**需要一台一直开着的电脑**（你家的、或对方家的）。想让对方家庭零维护、彻底不依赖某台家用电脑，就把 `server.mjs` 放到一台云服务器上，得到一个固定的 https 域名发给对方。对方手机打开 → 分享 → 添加到主屏幕，就成了一个永久在线的"假 app"。

### 三种托管方式怎么选（决策表）

| 方式 | 谁持钥匙 | 讯飞方言识别 | 对方要做什么 | 电脑要常开 | 适合 |
|------|----------|--------------|--------------|------------|------|
| **A 临时隧道** | 你 | ✅ 完整 | 点网址 | 你电脑必须开 | 开发调试 |
| **B Cloudflare Pages** | 你（存云 secret） | ❌ 无 | 点网址 | 不用 | 只打字/浏览器语音够了 |
| **C 命名隧道** | 你 | ✅ 完整 | 点网址 | 你电脑必须开 | 自己家长辈用 |
| **D 云服务器（本节）** | 你（存服务器 .env） | ✅ 完整 | 点网址 | 不用 | **正式交给别的家庭** |

**D 是唯一「完整能力 + 不依赖任何家用电脑常开」的方案。** 代价是每月有几块钱到几十块的服务器费用，和一次性部署维护。

### 机器配置要求（够用且便宜）

这套系统的服务端是**纯 Node 转发代理**，不跑任何本地 AI 模型推理：

- AI 对话 → 转发给 DeepSeek（云端 HTTP）
- 方言语音识别 → 转发给讯飞（云端 WebSocket）
- 温暖朗读 → 前端自动回退浏览器内置 TTS（不占服务器）

所以服务器只负责「转发 + 限流计数」，**2 核 2 GiB 内存已足够**（实测常驻几十 MB）。

实测可用配置（阿里云，最便宜的轻量机型）：

- 实例：`ecs.e-c1m1.large`（2 核 vCPU / 2 GiB）
- 系统：Alibaba Cloud Linux 3.2104 LTS 64 位
- 公网 IP：有
- 同配置的腾讯云 / 华为云 / 各大厂轻量应用服务器均可，本质一样。

> ⚠️ **不要**在 2G 机器上另起本地方言识别（`LOCAL_ASR_URL` / FunASR）或温暖朗读（`TTS_URL` / Qwen3-TTS）——那两个 Python 模型推理会吃掉大量内存，2G 会爆。D 方案下 `.env` **只配 DeepSeek + 讯飞两个 Key**，语音识别走讯飞云端即可，效果一致且省内存。

### 部署步骤

**1. 传代码到服务器**

本地（Windows，有 git）把项目推到一个私有仓库，再在服务器上克隆；或直接用 `scp` 传。二选一：

```bash
# 方式一：git 私有仓库（推荐，以后好更新）
git clone <你的私有仓库地址> renshengzhishu
cd renshengzhishu

# 方式二：scp 直传（不用仓库，从你电脑打包传过去）
# 在本地执行：
#   scp -r ./renshengzhishu root@<服务器公网IP>:/opt/renshengzhishu
```

**2. 在服务器上装 Node（Alibaba Cloud Linux 用 dnf）**

```bash
# 装 Node 18+（.mjs + fetch 都支持）
dnf install -y nodejs npm
node -v   # 确认 >= 18
```

> 如果 dnf 里的 Node 太旧（<18），用官方二进制：
> ```bash
> curl -fsSL https://rpm.nodesource.com/setup_20.x | bash -
> dnf install -y nodejs
> ```

**3. 配 .env（Key 只在这台服务器上）**

```bash
cd renshengzhishu
cp .env.example .env
vim .env   # 填 DEEPSEEK_API_KEY、XF_APPID、XF_API_KEY、XF_API_SECRET
# 保持 HOST=0.0.0.0，PORT=8788；LOCAL_ASR_URL 和 TTS_URL 留空不填
```

**4. 起服务 + 进程守护（关掉终端也在跑）**

用 `pm2`（或 systemd）保证重启后自动拉起：

```bash
npm install -g pm2
pm2 start server/server.mjs --name renshengzhishu
pm2 save               # 记住当前进程
pm2 startup            # 开机自启（会提示再执行一条它打印的命令）
```

验证：浏览器开 `http://<服务器公网IP>:8788`，能看到首页即成功。

**5. 绑域名 + https（麦克风/加桌面必须 https）**

手机用麦克风、加桌面都要求 https，所以必须套一个 https 域名：

```bash
# 前提：域名已托管在 Cloudflare（或你要用的 DNS 商）
# 用 cloudflared 命名隧道给 8788 套上 https（免证书、免改 nginx）
cloudflared tunnel create renshengzhishu
cloudflared tunnel route dns renshengzhishu shu.yourdomain.com
cloudflared tunnel run renshengzhishu   # 也用 pm2 守护它：
# pm2 start "cloudflared tunnel run renshengzhishu" --name cf-tunnel
```

得到 `https://shu.yourdomain.com`，发给对方家庭即可。

> 也可用 nginx + 免费 Let's Encrypt 证书替代 cloudflared，效果一样，只是多几步。

**6. 安全组 / 防火墙**

- 阿里云控制台 → 安全组 → 只放行 443 和 22（你管理用）。
- **不要**把 8788 直接暴露公网（会被扫端口刷 Key）。上一步用 cloudflared 隧道后，8788 只需服务本机，不用在安全组放行。
- 限流：`server.mjs` 自带每 IP 每分钟限流（`.env` 的 `RATE_PER_MINUTE`，默认 40），家庭自用够；若担心被刷，在 Cloudflare 加 WAF 规则。

### 更新代码

以后改了代码，服务器上更新：

```bash
cd renshengzhishu
git pull            # 如果用 git
pm2 restart renshengzhishu
```

### D 方案 vs B（Pages）一句话对比

- **D（云服务器）**：完整语音（含方言识别），固定域名，做真正的「长期给对方家庭用」，有少量服务器成本。
- **B（Pages）**：零服务器成本、零维护，但**没有方言识别**，语音降级为浏览器内置。
- 若方言不重要、只想最快交出去 → B；若方言是刚需、要完整体验 → D。

### 讯飞语音听写额度（够用，放心）

- D 方案的语音识别由**讯飞语音听写**云端完成（`/api/asr` 转发给讯飞，见 `server/xfyun-asr.mjs`）。
- **免费额度：每天 500 次，每日重置**，不是一次性。对「老人一句一按」的陪聊场景，单日有效说满 500 句并不容易，日常足够用。
- **新用户额外有一个免费包（5 万次，90 天有效）**，可在讯飞开放平台控制台领取，用于过渡。
- 若以后量上来了（如要「自动连续识别」），提额是**免费**的：讯飞开放平台控制台 → 提交应用审核 → 通过后升到 **2 万次/天**。这不是必须的，先不用管，500 够用就保持现状。
- 服务端对每 IP 每分钟还有 `RATE_PER_MINUTE` 限流（默认 40），也顺带保护讯飞额度不被刷。

**结论：不用额外花钱、不用提前提额，当前 500 次/天免费额度即可稳定运营。**
