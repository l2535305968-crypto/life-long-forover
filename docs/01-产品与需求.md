# 产品与需求

## 一句话

让 AI 以晚辈身份陪老人聊天，把普通人一生整理成"人生之书"。

## 两个用户

| | 老人 | 家人 |
|--|------|------|
| 是谁 | 会说、想讲、不识字或眼神不好、不说普通话 | 想留住长辈故事、会操作手机 |
| 痛点 | 没人听、问法生硬、不会打字 | 没时间、不会访谈、怕记不住 |
| 他要做 | **只管说话** | 开书、帮着把方言/原话敲成字、陪着 |
| 得到 | 被尊重、被倾听、被记住 | 一本能传给后代的家族传记 |

## 核心循环

家人开一本新书（起个称呼 + 选方言）→ 递手机给老人 → AI 开场并念出来 → 老人说 → 家人/输入法把话敲成字 → AI 顺着追问 → …… → 生成时间线和传记 → 加密导出给家人。

## 功能清单

- 访谈（核心）：AI 陪聊 + 追问引擎 + 拒绝/沉默/重复处理 + 敏感话题分寸
- 语音优先：AI 的话朗读；录音留原声
- 方言：东北/西安/天津/川渝/山东/河南/粤/吴 8 种 + 普通话，问句本地化、词表对照、易错音
- 家人协助：帮着转写、纠错
- 时间线：按人生阶段归拢
- 传记：只写老人真说过的话，文风 lint
- 隐私：本地存储 + 加密导出 + 授权码

## 明确不做（第一版）

- 不做登录/注册/账号体系
- 不做商家商城、不做社交、不做公域展示
- 不做专业语音识别接入（留接口，等 Key 和选型）
- 不编造老人的经历去"美化"传记

## 成功标准（可验证）

1. 老人从"开书"到"讲完一段话"，全程不需要打字（输入靠手机语音听写）。
2. AI 追问 50 轮内不出现一条"查户口"式问句（已有测试锁死）。
3. 传记正文里不出现一个编造的细节（文风规则 + lint 锁死）。
4. 数据不离开老人的手机，除非加密导出。
