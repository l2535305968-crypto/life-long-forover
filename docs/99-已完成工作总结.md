# 已完成工作总结

> 本文件记录《人生之书》从启动到当前这一轮，实际做出来的东西。每条都能在仓库里指到文件，不是口头承诺。

## 一、方向定了什么

| 决策 | 结论 |
|------|------|
| 形态 | 家人发起的 PWA（手机"添加到主屏幕"= 一个大图标），老人只管说话 |
| 联网 | 必须联网。DeepSeek 负责"怎么聊"，语音先靠手机输入法听写，方言 ASR 留接口 |
| 部署 | 本机 `node server/server.mjs` 开发；真机用 cloudflared https；正式可托管 Cloudflare Pages |
| 隐私 | Key 只在服务端；老人内容只存自己手机；服务端不落盘、不打印正文 |

## 二、做出来的东西（按层）

### 数据资产（3 份，都是纯数据、可机器检查）
- `web/js/core/bank.js`：173 条具体问题 + 48 条触发式追问规则 + 拒绝/沉默/重复/开场/收尾/没听清六类话术。
- `web/js/core/prose.js`：30 条成稿禁令（冒号、破折号、"不是而是"、商业黑话等）+ 24 条警告词 + 38 条传记模板 + 57 条真实时代锚点。
- `web/js/core/dialects.js`：9 个方言包（东北/西安/天津/川渝/山东/河南/粤/吴/普通话），词表 + 亲属称谓 + 问句本地化 + 易错音。

### 核心引擎（确定性内核，可测）
- `intent.js`：分清老人是拒绝、沉默、重复，还是真往下讲了。
- `model.js`：会话数据结构（档案、时间线片段、录音、授权码）。
- `engine.js`：访谈状态机。追问链限深（深度 2 次转广度）、敏感话题看暖场、拒绝进黑名单、重复不点破、开场带出第一个具体问题。
- `biography.js` / `timeline.js`：传记生成（只写真话）+ 文风 lint；人生时间线。

### 服务端（Key 的边界）
- `server/server.mjs`：静态服务 + `/api/chat` 代理 + `/api/health`。限流、目录穿越防护、不落盘、不打印正文。
- `server/env.mjs` + `.env.example`：读配置。

### AI 适配层
- `ai/prompt.js`：把访谈铁律翻译成模型指令。
- `ai/adapter.js`：DeepSeek 润色问题；断网/没 Key 自动退回引擎的确定性问句，访谈不中断。

### 隐私
- `crypto.js`：AES-256-GCM + PBKDF2 加密导出，没口令打不开。
- `storage.js`：IndexedDB 本地存储。

### 照片（老照片翻页）
- `model.js`：`addImage` / `removeImage`，照片存为 dataURL 字符串（能进 IndexedDB、也能导出/导入）。
- `image.js`：把上传的老照片压到最长边 1600px 的 JPEG，翻页不卡、存储不爆。
- 前端：底部「照片」tab → 插入照片 → 全屏翻页查看器（照片作为 CSS 背景显示，左右大按钮 + 触摸滑动 + 键盘 ←→ 翻页，页码、删图、caption）。

### PWA 外壳
- `manifest.webmanifest`、`sw.js`、`icons/icon-512.png`、`icon-192.png`（纯 Node 手写 PNG 编码生成）。
- `tts.js`（朗读给老人听）、`recorder.js`（录音留原声）。

### 测试
- `test/run-all.mjs` 一键跑全部，当前 **9/9 通过**：3 份数据自检 + 意图识别 + 引擎行为 + 传记 lint + 加密往返 + 照片模型 + 端到端集成。

### 文档
- `docs/00-项目计划与分工.md`、`docs/01-产品与需求.md`、`docs/03-访谈方法论.md`、`docs/04-隐私与安全.md`、`README.md`。

## 三、验证过的关键点

- 目录穿越请求返回 403（curl 实测）。
- 无 Key 时 `/api/chat` 返回 503，不暴露 Key。
- 引擎 50 轮冷启动，问句里不出现"叫什么名字 / 多大岁数 / 住址 / 身份证"。
- 老人说"苞米"必追"那细粮留着啥时候吃"，不随机。
- 拒绝过的话题不会再被冷启动问到。
- 加密往返、错误口令打不开。
- 前端全部静态资源 serve 200（冒烟实测）。

## 四、评审发现并修复（代码审查）

- 修复：只有录音、没有文字时，占位句不再被当成老人的话喂给引擎（避免污染时间线和传记）。
- 修复：照片查看器的 inert 焦点圈不再误伤 `<dialog>` 确认框（否则"删掉这张"按钮点不动）。
- 修复：录音原声从 Blob 改成 dataURL 存储（`recorder.blobToDataUrl`），随书加密导出不再丢原声；时间线加了「▶ 播放原声」。

## 五、真实 DeepSeek 联调（已验证）

- `.env` 配好 Key 后，`/api/health` 返回 `hasKey:true`。
- 实测一条访谈追问，模型回话：「那细粮可稀罕了吧？是不是就逢年过节才舍得吃一回？」——短、暖、顺着上一句接，符合预期。
- 全链路：`ai/prompt.js`（提示词）→ `server.mjs`（代理）→ DeepSeek，HTTP 200。
