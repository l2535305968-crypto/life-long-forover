# 人生之书

让 AI 以**晚辈**的身份陪老人聊天，把普通人的一生，整理成一本有人味儿的书。

史书只记王公贵族。普通人的人生，凭什么不能被记下来。

## 它是什么

- **AI 陪聊，不是查户口**。问题具体到生活细节（"小时候最愿意吃啥饭"），顺着老人上一句话往下问，允许拒绝、允许沉默、允许重复。
- **老人只管说话**。界面字号大、按钮大，AI 的话会念出来；家人负责开、负责帮着把老人的话敲成字。
- **人生时间线 + 传记**。聊下来的东西按童年、上学、青年、成家、中年、晚年归拢，最后生成一本只写老人真说过的话的传记。
- **老照片翻页**。把老照片放进来，全屏翻页看（照片作为背景显示，左右按钮 / 滑动 / 键盘都能翻）。
- **隐私是底线**。数据只存在老人自己的手机里，不上传；发给家人看要用口令加密。

## 把它当 SDK 用（安卓手机 / 脚本 / 别的网页）

整套系统已封装成服务端 API + 客户端 SDK：访谈引擎、AI 对话、传记、时间线、语音识别都能远程调用。
手机 App 接入只需三步：起服务 → 连上 → `newSession` → `conv.say(...)`。

- 接口清单与错误码：[docs/08-SDK接入.md](docs/08-SDK接入.md)
- JS SDK：`sdk/js/`（`SdkClient` / `Conversation`）
- Android SDK：`sdk/android/`（`RenshengClient` / `Conversation`，零依赖，Android Studio 打开即用）

隐私底线不变：照片、录音、日志在客户端发请求前就被剥掉，服务端永远看不到；Key 只在服务端。

## 快速开始

1. **配 Key**：把 `.env.example` 复制成 `.env`，填 `DEEPSEEK_API_KEY=sk-xxxx`。
2. **起服务**：`node server/server.mjs`（或 `npm start`）。
3. **本机验证**：浏览器开 `http://localhost:8788`。localhost 是安全环境，麦克风、加桌面都能试。
4. **手机真机**：手机要麦克风 + 加桌面必须是 https。临时办法：
   `cloudflared tunnel --url http://localhost:8788`，会吐一个 https 网址，微信里发给家人点开即可。

> 正式部署到 Cloudflare Pages（自带 https、能加桌面、能用麦克风），见 [`docs/05-部署.md`](docs/05-部署.md)。

## 测试

```
node test/run-all.mjs
```

覆盖：话术库/文风/方言三份数据自检、意图识别、访谈引擎行为（拒绝/沉默/重复/敏感话题分寸/不查户口）、传记文风 lint、加密往返。

## 隐私（不是口号，是代码）

- DeepSeek Key 只在 `server.mjs`，手机永远拿不到。
- 服务端不落盘、不打印任何老人说的话；日志只有时间、路径、状态码。
- 老人的书存在自己手机的 IndexedDB，联网只为"让 AI 说得自然"。
- 导出给家人时，用 AES-256-GCM + 口令加密，没口令谁也打不开。

## 已知限制（诚实）

- **方言转文字**当前靠手机输入法自带的语音听写（这是大陆最可靠的现实办法），专业方言 ASR 留了接口待接。
- 局域网 `http://192.168.x.x` 拿不到麦克风，真机必须 https。
- 传记只写老人真说过的话，素材不够时宁可短，不编。
